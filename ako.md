# Cybersecurity Basics & Notes

## Networking Terms
* *IP Address:* An identifier for a device on a network.
* *IP Spoofing:* Masquerading as another system by falsifying IP data.
* *MAC Address:* A unique physical identifier assigned to a network interface card (NIC).
* *DNS (Domain Name System):* Translates human-readable domain names to IP addresses.
* *Port Scanning:* Discovering open ports and services available on a network host.
